# Подключение локального infra gate к CI

Пользователь согласовал этап 14 октября 2026 года: подключить ту же команду к CI и сделать коммит в текущей ветке.

Workflow запускается на каждом PR в main, push в main и вручную, без фильтров путей. GitHub-hosted Ubuntu 24.04 собирает backend из существующего Dockerfile и lock-файлов, затем выполняет `make agent-infra-test`. Другой selection не вводится. Ненулевой exit build/test сохраняется при записи логов; evidence загружается всегда. Actions закреплены SHA, checkout не сохраняет credentials, permissions ограничены contents: read.

В коммит входят необходимые infra-модули согласованных локальных этапов и их тесты: они ещё не отслеживаются в HEAD. Посторонние изменения рабочего дерева исключаются. Makefile и старый network-cleanup regression включаются отдельными изменениями, без остальных правок этих файлов.

Приёмка: RED/GREEN workflow-контракт; реальная проверка shell failure propagation; actionlint, Ruff и scoped mypy; сборка образа и полный infra gate из отдельной копии будущего коммита; независимое Standards/Spec ревью. Реальный GitHub Actions run и branch-protection settings остаются NOT_RUN до публикации ветки.
