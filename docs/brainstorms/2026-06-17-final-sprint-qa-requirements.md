## Потоки в порядке выполнения

### 1. M:N: Объект → Договоры

**Почему первым:** изолирован, нет зависимостей, быстро.

**Маршрут:** `/dashboard/objects/{id}` → таб «Договоры»

Проверить:
- `+ Привязать договор` → modal с UUID-инпутом → submit → строка появилась
- Кнопка «→» переводит на страницу договора
- Кнопка «Отвязать» → строка исчезла

**Риск:** UUID надо знать заранее. Взять из `/dashboard/contracts` (скопировать из ID-поля любого договора).

---

### 2. Contract 360°: финансы / вложения / история

**Маршрут:** `/dashboard/contracts/{id}`

Проверить:
- **Последние платежи** — есть данные или «Проведённых платежей нет»; ссылка «Все платежи →» ведёт в Finance
- **Вложения** — «Прикрепить файл» → пикер файлов → прикрепить → статус AVAILABLE → кнопка «Скачать» / «Открепить»; закрытие договора без вложений должно быть заблокировано
- **История** — показан EventTimeline (ContractCreated/Activated события)
- **Объекты** — ObjectsSection: видны привязанные объекты (read-only)

**Риск:** для AttachmentsSection нужен хотя бы один файл в статусе AVAILABLE в `/dashboard/files`. Если файлов нет → увидим «Нет доступных файлов».

---

### 3. Заявки end-to-end

**Маршрут:** Публичный сайт → дашборд `/dashboard/requests`

#### 3a. Форма обратной связи (публичный сайт)

Маршрут: `http://localhost:3000` (или `/contacts`)

- Заполнить: Имя, Телефон, Адрес, Тип услуги
- Turnstile invisible — **не требует ручного действия**, token выдаётся автоматически (dev key `1x00000000000000000000AA`)
- Submit → «Заявка принята!»

#### 3b. Дашборд: найти заявку

- `/dashboard/requests` → новая заявка с статусом NEW вверху списка
- Открыть → статус NEW, кнопки: «Назначить менеджера» (единственная активная)

#### 3c. Workflow NEW → ASSIGNED → PROCESSING → Object

| Шаг | Действие | Ожидание |
|---|---|---|
| NEW | «Назначить менеджера» → modal → выбрать → «Назначить» | Статус → ASSIGNED, кнопка «Взять в обработку» |
| ASSIGNED | «Взять в обработку» | Статус → PROCESSING, кнопка «Конвертировать в объект» |
| PROCESSING | «Конвертировать в объект» → confirm | Redirect на `/dashboard/objects/{new_id}` |

#### 3d. Object 360° (после конвертации)

- Страница объекта открылась
- Таб «Основное»: имя, адрес из заявки, статус NEW
- Таб «Этапы»: чеклист этапов (если настроены)
- Таб «Договоры»: пусто, кнопка «+ Привязать договор» есть

## Критические риски

| Риск | Вероятность | Mitigation |
|---|---|---|
| Turnstile не отдаёт токен | Низкая (dev key по умолчанию) | Проверить в консоли нет ли ошибки Turnstile |
| granian hot-reload завис | Средняя (WSL2 баг) | `docker compose -f docker-compose.dev.yml restart backend` |
| Нет файлов AVAILABLE для вложения | Средняя | Сначала загрузить файл в `/dashboard/files` |
| ContractRow показывает UUID а не название | Факт (code smell) | Ожидаемое поведение, не баг до рефактора |

---

## Что НЕ тестируем в этом спринте

- Привязка объекта из договора — UI не реализован (из договора только просмотр)
- Финансы/файлы в Object 360° — этих секций в объекте нет, они в Contract 360°
- Shell, SQL, прямые API-вызовы — тест только через браузер
