# 0002 — Zero-Downtime Migration Governance (Expand & Contract)

## 1. Статус

## 2. Контекст

Система работает в режиме ASGI Only (Granian/Uvicorn) под высокой транзакционной нагрузкой. Классические деструктивные миграции (`AddField NOT NULL`, `RemoveField`, `AlterField`) накладывают на PostgreSQL блокировку `AccessExclusiveLock`, которая останавливает все читающие и пишущие потоки. Это выжигает Error Budget и нарушает SLA 99.9%.

---

## 3. Решение

Зафиксировать закон **Expand & Contract** — любое изменение схемы данных разбивается строго на 3 релиза.

### Правила

#### Релиз N — Expand (Расширение)

- Добавляется только nullable колонка или новая таблица.
- Старый код продолжает работать без изменений.

#### Релиз N+1 — Switch (Переключение)

- Запускается асинхронный Celery-батч: копирует данные из старой колонки в новую батчами по 5000 строк через `SKIP LOCKED`.
- Бэкенд начинает писать в обе колонки, читать — из новой.

#### Релиз N+2 — Contract (Сужение)

- Накладывается `NOT NULL` через `NOT VALID`, затем `VALIDATE CONSTRAINT` (без полной блокировки таблицы).
- Старая колонка удаляется.

### Запреты (блокируются CI/CD Quality Gate)

- `AddField` с флагом `NOT NULL` без `default`.
- `RemoveField` или `AlterField` (смена типа) на активных колонках текущей ветки.
- Создание индексов без директивы `CONCURRENTLY`.
- Миграции без `reverse_sql` или зеркального `backwards()`.

---

## 4. Рассмотренные альтернативы

| Альтернатива             | Причина отказа                                                          |
| ------------------------ | ----------------------------------------------------------------------- |
| Обычный ALTER TABLE      | Вызывает `AccessExclusiveLock`, останавливает весь трафик на время DDL. |
| Online DDL через pt-osc  | Требует Percona Toolkit, несовместим с PostgreSQL.                      |

---

## 5. Последствия

### Плюсы

- 100% аптайм БД во время деплоя.
- Нулевые блокировки транзакционного ядра.
- Возможность мгновенного отката через `backwards()`.

### Минусы

- Одна фича с изменением структуры данных занимает минимум 2–3 релиза.
- Требует строгой дисциплины ревью миграций.
