# 0003 — OpenAPI Schema Freeze Policy для версии /api/v1/

## 1. Статус

| Поле     | Значение                                      |
| -------- | --------------------------------------------- |
| Статус   | APPROVED                                      |
| Дата     | 2026-05-24                                    |
| Владелец | Core Architecture Lead / Frontend Lead        |

---

## 2. Контекст

Фронтенд полностью зависит от автогенерируемого TypeScript SDK (`frontend/src/shared/api/generated/`). Ручное изменение Pydantic DTO-схем без контроля обратной совместимости приводит к падению TypeScript-компиляции на фронтенде во время релиза и выжигает Error Budget REST API (SLO 99.9%).

---

## 3. Решение

Ввести политику заморозки схемы OpenAPI для живой мажорной версии `/api/v1/`.

### Запреты

- Удаление endpoint'ов, HTTP-методов, query-параметров или полей из Response DTO.
- Изменение типа существующих полей (например, `uuid.UUID` → `str`).
- Добавление новых **обязательных** полей в Request DTO или новых обязательных параметров без дефолтных значений.

### Разрешено

- Добавление новых endpoint'ов.
- Добавление новых опциональных (nullable) полей в Response DTO.
- Добавление необязательных query-параметров с дефолтным значением.

### Процедура breaking change

Любое деструктивное изменение выносится в изолированный роут новой мажорной версии `/api/v2/` с обязательным 6-месячным Migration Window.

---

## 4. Рассмотренные альтернативы

| Альтернатива                    | Причина отказа                                                       |
| ------------------------------- | -------------------------------------------------------------------- |
| Версионирование на уровне поля  | Неуправляемый рост сложности DTO; высокий риск непреднамеренных багов. |
| Без заморозки                   | Гарантированные краши SDK на фронтенде при каждом рефакторинге.     |

---

## 5. Последствия

### Плюсы

- Фронтенд полностью защищён от изменений бэкенда в рамках мажорной версии.
- Контракт между командами железобетонен.

### Минусы

- Разработчики не могут быстро переименовать поле — требуется миграция через новую версию.
