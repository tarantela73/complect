# Complect ADR format

Use the existing [ADR template](../../../docs/adr/TEMPLATE.md) and
[ADR register](../../../docs/adr/). Preserve status, owner, context, decision,
alternatives, consequences and related decisions as applicable to that template.
An agent proposal does not become Accepted merely by being written.

Offer an ADR only for a decision that is hard to reverse, surprising without
context and involves genuine alternatives. Pure vocabulary clarifications belong
in CONCEPTS.md. Inspect current numbering and concurrent work before choosing a
new number. Update the related plan/contract/runbook/tests when the accepted
decision changes; do not silently overwrite an accepted decision from a skill.
